# scratch

A personal catch-all repo for small scripts, notes, snippets, and miscellaneous experiments.

## Layout

- `scripts/` — standalone scripts (PowerShell, Python, Bash, etc.)
- `snippets/` — reusable code fragments and one-liners
- `notes/` — markdown notes, references, and ideas

## Conventions

- One folder per language or topic when things start to grow.
- Prefer descriptive filenames over deep nesting.
- A short comment header at the top of each script: what it does and how to run it.
